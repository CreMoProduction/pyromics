# About
Pyromics is a high-performance, user-frie\nndly desktop application engineered to streamline the analysis of Py-GC/MS data. Designed specifically for the characterization of lignocellulosic biomass.

Pyromics is developed at the Biopolymer Analytical Platform (BAP) at the Umeå Plant Science Centre (UPSC) in Umeå, Sweden.

This documentation provides information about Pyromics software and usage guidance.
